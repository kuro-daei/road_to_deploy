# 04. Markdownをマスターしよう

Markdown は、シンプルな記法でドキュメントを書くための軽量マークアップ言語です。
GitHub の README や、このドキュメント自体も Markdown で書かれています。

---

## 1. Markdown とは

テキストファイル（拡張子 `.md`）に決まった記法で書くと、
見出し・リスト・表などを備えたきれいなドキュメントに変換されます。

```
# 見出し      →  大きなタイトル
**太字**       →  太字のテキスト
- リスト       →  箇条書き
```

---

## 2. VS Code でプレビューする

VS Code では Markdown をリアルタイムにプレビューできます。

### プレビューを開く

1. `.md` ファイルを VS Code で開く
2. 右上の「プレビューを開く」アイコン（本のアイコン）をクリック
   - またはショートカット: `Ctrl + Shift + V`
3. エディタの隣にプレビューが表示される

### 分割表示（編集しながらプレビュー）

1. `.md` ファイルを開いた状態で `Ctrl + K` を押してから `V` を押す
2. 左にエディタ、右にプレビューが並んで表示される

## 3. Markdown 記法

### 見出し

`#` の数で見出しレベルが変わります。

```markdown
# 見出し1（最大）
## 見出し2
### 見出し3
#### 見出し4
```

### テキスト装飾

```markdown
**太字**
*斜体*
~~打ち消し線~~
`インラインコード`
```

表示例：

- **太字**
- *斜体*
- ~~打ち消し線~~
- `インラインコード`

### 段落と改行

空行を入れると段落が区切られます。

```markdown
最初の段落です。
この行は同じ段落に含まれます。

こちらは新しい段落です。
```

### リスト

**箇条書き（順序なし）**

```markdown
- アイテム1
- アイテム2
  - ネストしたアイテム
  - さらにネスト
- アイテム3
```

**番号付きリスト（順序あり）**

```markdown
1. 最初のステップ
2. 次のステップ
3. 最後のステップ
```

### リンク

```markdown
[リンクテキスト](https://example.com)
[相対リンク](./02_github_start.md)
```

### 画像

```markdown
![代替テキスト](./images/screenshot.png)
![代替テキスト](https://example.com/image.png)
```

### コードブロック

バッククォート3つで囲み、言語名を指定するとシンタックスハイライトが付きます。

````markdown
```bash
git add .
git commit -m "feat: 変更を追加"
git push
```
````

````markdown
```python
def hello():
    print("Hello, World!")
```
````

### 引用

```markdown
> これは引用文です。
> 複数行にまたがることもできます。
>
> 空行を入れると段落が分かれます。
```

表示例：

> これは引用文です。
> 複数行にまたがることもできます。

### 水平線

```markdown
---
```

または `***`、`___` でも同じ水平線になります。

### 表（テーブル）

```markdown
| 列1 | 列2 | 列3 |
|---|---|---|
| セルA | セルB | セルC |
| セルD | セルE | セルF |
```

列の配置を指定できます：

```markdown
| 左寄せ | 中央 | 右寄せ |
|:---|:---:|---:|
| テキスト | テキスト | テキスト |
```

### チェックボックス

```markdown
- [x] 完了したタスク
- [ ] 未完了のタスク
- [ ] また別のタスク
```

## 4. よく使う記法のまとめ

| 記法 | 表示 |
|---|---|
| `# テキスト` | 見出し1 |
| `## テキスト` | 見出し2 |
| `**テキスト**` | **太字** |
| `*テキスト*` | *斜体* |
| `` `コード` `` | `インラインコード` |
| `- アイテム` | 箇条書き |
| `1. アイテム` | 番号付きリスト |
| `[文字](URL)` | リンク |
| `---` | 水平線 |

## 5. ブランチ経由で Markdown ファイルを push する実践

ここまで学んだ Git ブランチと Markdown を組み合わせて、実際に作業します。

### 手順

**1. 作業ブランチを作成する**

```bash
git checkout -b docs/add-about-md
```

**2. Markdown ファイルを作成する**

```bash
code about.md
```

VS Code で以下のような内容を書いて保存します。

```markdown
# About

## このプロジェクトについて

このリポジトリは Git と GitHub の練習用プロジェクトです。

## 使い方

1. リポジトリをクローンする
2. 各ドキュメントを読む
3. コマンドを試してみる
```

**3. commit する**

```bash
git add about.md
git commit -m "docs: Aboutページを追加"
```

**4. GitHub に push する**

```bash
git push -u origin docs/add-about-md
```

**5. main にマージする**

```bash
git checkout main
git pull                          # 最新の main を取得
git merge docs/add-about-md
git push
```

**6. ブランチを削除する**

```bash
git branch -d docs/add-about-md
git push origin --delete docs/add-about-md
```
