# road_to_deploy — ドキュメント一覧

このドキュメントセットは、WSL・VS Code・Git・GitHub を使った開発フローを
一から学ぶための実践的なガイドです。

---

## 対象読者

- Git や GitHub を使ったことがない、または使い始めたばかりの方
- WSL (Windows Subsystem for Linux) 環境でプログラミングを始めたい方
- ブランチを使ったチーム開発の基礎を身につけたい方

---

## ドキュメント構成

| ファイル | タイトル | 内容 |
|---|---|---|
| [01_setup.md](./01_setup.md) | 環境構築 | WSL・VS Code・Git・GitHub の初期設定 |
| [02_github_start.md](./02_github_start.md) | GitHubをはじめよう | リポジトリ作成・commit・push の基礎操作 |
| [03_git_branch.md](./03_git_branch.md) | Gitのブランチをマスターしよう | ブランチの概念・作成・切り替え・merge |
| [04_markdown.md](./04_markdown.md) | Markdownをマスターしよう | Markdown記法・VS Codeプレビュー活用 |
| [05_command_reference.md](./05_command_reference.md) | コマンドリファレンス | よく使う Git コマンドの早見表 |

---

## 学習の進め方

```
01_setup.md
    ↓  環境が整ったら
02_github_start.md
    ↓  基本操作を覚えたら
03_git_branch.md
    ↓  ブランチを使えるようになったら
04_markdown.md
    ↓  いつでも参照
05_command_reference.md
```

各ドキュメントは順番に読み進めることを推奨しますが、
「コマンドが分からなくなったら `05_command_reference.md` を参照する」
といった使い方も想定しています。

---

## 前提条件

- Windows 10 / 11 が動作する PC
- インターネット接続
- GitHub アカウント（[github.com](https://github.com) で無料作成可能）
